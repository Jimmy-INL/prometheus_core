Practice PR to sandbox, with a rebase

cd ~/prometheus/prometheus_platform
git fetch upstream
git switch -c feature/hello-<you> upstream/sandbox

mkdir -p hackathon/<you>
cp ../hello-<you>/{agent.py,agent_card.json,README.md} \
   hackathon/<you>/
git status                     # NO .env in the list!
git add hackathon/<you>
git commit -m "Add hello-world agent for <you>"

# someone else merged first? replay on top
git pull --rebase upstream sandbox

git push -u origin HEAD        # later: git push --force-with-lease
gh pr create --repo genesis/prometheus_platform \
  --base sandbox --head <you>:feature/hello-<you> \
  --title "Practice: hello from <you>" \
  --body "Dry-run PR. Tested: uv run pytest, routed in UI."
  1. Ask your neighbour to review: gh pr view <n> --web
  2. Reviewer: leave one inline comment
  3. Author: push a fix commit and reply "Fixed in <sha>"
  4. Reviewer: resolve the thread and approve
  5. A mentor merges
Base is sandbox, never dev. --force-with-lease only on your own feature branch.
