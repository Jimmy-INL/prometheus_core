LLM

import os
from prometheus_api.llm_client import (
    LLMConfig, ToolDefinition, acall_tool)

cfg = LLMConfig.from_env().with_api_key(
    os.getenv("LITELLM_MASTER_KEY"))
async with self.llm_client(context, config=cfg) as llm:
    r = await llm.small("…")          # r.text
    call = await acall_tool(llm, prompt, tool=PICK,
                            model="small")
    idx = call.arguments["index"]

Flavors: small, medium, large, vision, embedding. Each one must exist in the platform's litellm_config.yaml (check /v1/models).

Long work

  • Blocking code: await asyncio.to_thread(fn, …)
  • With progress: a PrometheusWorker run via await self.run_worker(worker, context, event_queue)
  • Minutes or more: await self.declare_long_running(context, event_queue, estimate_seconds=…)

Packaging

  • Your imports in pyproject.toml (pandas, matplotlib); never prometheus_api
  • MPLBACKEND=Agg; a COPY line in the Dockerfile per extra module
  • uv run pytest and uv run ruff check . must pass
