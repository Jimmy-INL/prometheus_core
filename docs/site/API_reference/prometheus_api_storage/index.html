Prometheus API - Storage Client¶

Storage Client Library - A generic abstraction for storage backend operations.

APIError ¶

Bases: StorageClientError

Raised when the API returns an error response.

AsyncStorageClient ¶

Asynchronous client for storage backend operations.

This client provides a high-level async interface for interacting with the storage backend, including CRUD operations for items, file management, relationships, and search functionality.

Example 
config = ConnectionConfig(
    organization_id=123,
    project_id=456,
    api_key="key",
    api_secret="secret"
)

async with AsyncStorageClient(config) as client:
    item = await client.items.create(ItemCreate(name="Test"))
    results = await client.search.query("test")

from_env(env_file=None, organization_id=None, project_id=None, **kwargs) classmethod ¶

Create configuration from environment variables.

Loads credentials from environment variables or a .env file.

Expected environment variables: - DEEPLYNX_KEY: API key for authentication - DEEPLYNX_SECRET: API secret for authentication - DEEPLYNX_ORG_ID: Organization ID (optional if passed as parameter) - DEEPLYNX_PROJECT_ID: Project ID (optional if passed as parameter) - DEEPLYNX_BASE_URL: Base URL (optional) - DEEPLYNX_JWT_TOKEN: JWT token (alternative to API key/secret)

Parameters:

Name Type Description Default
env_file Optional[Path]

Optional path to .env file (default: searches for .env in current dir)

 None

 None

Example 
# Load from .env file in current directory
config = ConnectionConfig.from_env()

# Load from specific .env file
config = ConnectionConfig.from_env(env_file=Path("/path/to/.env"))

# Override with parameters
config = ConnectionConfig.from_env(
    organization_id=123,
    project_id=456
)
