01

The shared bus

A2A JSON-RPC 2.0 over HTTP carries every request. Discovery, routing, and LLM calls all flow through LiteLLM; state and artifacts live in Redis.

02

Two layers, cleanly split

The transport & contract layer is shared by everyone. The reasoning layer is private to each agent — frameworks like LangGraph never cross an agent boundary.

Shared · the bus

Transport & contract

PrometheusAgent (in prometheus_api/agent/base.py) wraps the a2a-sdk: AgentExecutor, RequestContext, EventQueue, AgentCard — served on Starlette + uvicorn. Subclasses implement one method, async _execute(), and inherit artifact handling, status streaming, DeepLynx storage, and Redis state.

a2a-sdk Starlette + uvicorn LiteLLM gateway + registry Redis state / artifacts
Private · per agent

Reasoning & orchestration

Inside _execute(), each agent picks whatever orchestration model fits its problem. The platform makes no demand here — a graph, a tool loop, a stateful session runner, or plain imperative code are all equally valid as long as the agent emits A2A events.

LangChain LangGraph Google ADK …or nothing

Three agents, three frameworks

Each chose its framework to match the shape of its work — not because the platform mandated it.

A real multi-stage DAG: parse → transform → validate → generate → convert → finalize, with retries. Exactly what StateGraph is for. Backed by Flask + Celery + Redis for heavy geometry jobs.

Cubit Agent

Google ADK

A stateful, tool-driven runner with MCP toolsets and session persistence — ADK sessions hold the live Cubit notebook state across clarification round-trips, so a paused workflow resumes where it left off.

04

One thread runs through all of it: LiteLLM

It is the single piece of LLM plumbing common to every agent — appearing at two different altitudes.

The one-sentence version

A2A is the contract between agents; the orchestration framework is a private implementation detail of each agent. LangGraph isn’t a platform-wide choice — it’s the BIM agent’s choice because its workflow is graph-shaped.

The orchestrator deliberately doesn’t use it (a plain LangChain loop), and Cubit reaches for Google ADK instead because it needs stateful sessions. The PrometheusAgent base class is what makes this heterogeneity invisible: implement _execute(), emit A2A events, and you can run any framework inside — or none.
