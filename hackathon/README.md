# Prometheus agent hackathon

This repository holds the hackathon agents: `practice/<you>/` on Day 1, `agents/<team_name>/` on
Day 2.

- **With Claude Code.** Start `claude` in the root of this repository. Type `/diagnose` to check
  your laptop, `/create-agent` to start an agent, or `/how <question>`. `CLAUDE.md` lists the
  skills.
- **Without Claude Code.** Read `.claude/skills/how/references/index.md`: plain markdown, with
  the commands that the skills run.
- **Mentors.** Ask in the room. `.claude/skills/how/references/mentors.md` names who knows what.
- **Forked before the skills arrived?** Run `git pull --rebase upstream main`.
