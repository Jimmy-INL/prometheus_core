Prometheus API - Agent¶

Agent utilities for building A2A (Agent-to-Agent) multi-agent systems.

BearerTokenMiddleware ¶

Bases: BaseHTTPMiddleware

Middleware to verify Bearer token authentication for A2A requests.

Validates that all incoming requests contain a valid Bearer token in the Authorization header matching a configured secret.

Parameters:

Name Type Description Default
app

The Starlette application

 required
secret str

The shared secret for authentication (optional, reads from AGENT_SECRET env var)

 None
required bool

Whether authentication is required (default: True)

 True
Example

from starlette.applications import Starlette from agent.middleware import BearerTokenMiddleware

app = Starlette() app.add_middleware(BearerTokenMiddleware, secret="my-secret", required=True)

Environment Variables

AGENT_SECRET: The shared secret for authentication AGENT_SECRET_REQUIRED: Whether to enforce authentication (default: true)

Security Notes
  • Health check (/health) and agent card (/.well-known/agent.json) endpoints are exempt
  • Token values are never logged (only validation status)
  • Returns 401 Unauthorized with JSON-RPC 2.0 error format on failure

PrometheusAgent ¶

Base class for Prometheus A2A agents.

This class handles all the boilerplate: - Loading agent card from JSON - Setting up Bearer token authentication - Registering with the registry - Starting the HTTP server with A2A protocol

To create an agent: 1. Inherit from PrometheusAgent 2. Override process_analysis() method 3. Call run()

Example 
from prometheus_api.agent import PrometheusAgent

class MyAgent(PrometheusAgent):
    def process_analysis(self, params, event_queue):
        # Your logic here
        return {"status": "success"}

if __name__ == "__main__":
    agent = MyAgent(agent_name="My Agent")
    agent.run()

async def process_analysis(self, params, context, event_queue):
    input_data = params.get("input_data")

    # Send progress update
    await event_queue.enqueue_event(
        TaskStatusUpdateEvent(
            taskId=context.task_id,
            contextId=context.context_id,
            final=False,
            status=TaskStatus(state=TaskState.working),
        )
    )

    # Your logic here
    result = do_work(input_data)

    return {"status": "success", "result": result}

run(host='0.0.0.0', port=None) ¶

Start the agent HTTP server.

This method: 1. Loads the agent card 2. Creates the executor 3. Sets up the HTTP server with A2A protocol 4. Adds Bearer token authentication 5. Registers with the registry 6. Starts the server

PrometheusAgentExecutor ¶

Bases: AgentExecutor

Base executor for Prometheus agents.

Handles parameter extraction, status updates, and error handling. Subclasses only need to implement process_analysis().
